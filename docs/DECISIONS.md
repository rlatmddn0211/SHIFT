# SHIFT 확정 사항과 질문 목록

이 문서는 제품 기획 중 사용자가 확정한 선택과 답변이 필요한 항목을 관리한다. 구현 가능성 검증은 사용자 선호와 별도로 기록한다.

## 기술 검증 사항

- OneNote는 Microsoft Graph의 사용자 위임 인증과 필요한 권한으로 연결하는 방식을 검증한다.
- YouTube Data API의 재생목록 조회 기능과 YouTube Music 라이브러리 및 실제 차량 재생은 서로 구분해 검증한다.
- 공개적으로 지원되는 음악 재생 경로를 확인하기 전에는 실제 구현이 가능하다고 확정하지 않는다.
- 차량 주행 상태와 기능 제한은 앱 카테고리 및 CarUxRestrictions를 기준으로 검증한다. 물리적 차량 설정 기능은 이번 출품에서 제외한다.
- 반납 정리는 SHIFT가 관리하는 개인 세션과 데이터를 기준으로 하며, 차량 전체 또는 타 앱의 모든 이력 삭제를 전제하지 않는다.
- 로컬에는 Android Studio, Android SDK, 에뮬레이터 실행 파일, 내장 Java, Node.js와 npm이 존재한다. Pleos AVD 실행과 SDK 빌드는 아직 검증하지 않았다.
