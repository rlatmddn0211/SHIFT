# SHIFT v1.2 Figma

[편집용 Figma 페이지](https://www.figma.com/design/yICJ7aqxqub9JIPyEZX2BC/?node-id=11-528) · [클릭 시연 시작](https://www.figma.com/proto/yICJ7aqxqub9JIPyEZX2BC/?page-id=11%3A528&node-id=11-539&starting-point-node-id=11%3A539&scaling=scale-down)

기존 Figma 작업 파일의 **03 · SHIFT v1.2 시연** 페이지에 차량과 휴대폰 화면 26개를 만들고 52곳을 연결했다. 제목, 버튼 레이블, 방문 카드와 업무 내용은 레이어에서 수정할 수 있다. 버튼은 페이지 왼쪽의 공통 컴포넌트로 수정하고, 클릭 이동은 오른쪽 **프로토타입** 탭에서 편집한다. 배경, 남색 카드와 강조색은 기존 파일의 SHIFT 색상 변수를 사용한다.

- 차량 대기에서 휴대폰 PIN 승인으로 이동하면 직원 A의 오늘 방문 업무를 볼 수 있다.
- 대시보드에서 장소 변경 근거, 내비 결과, 업무 브리핑, 시트, 음성 메모와 주행 제한을 볼 수 있다.
- QR 로그아웃을 승인하면 공용 대기가 열리고 직원 B의 PIN 승인 후 B의 일정이 표시된다.
- 모바일 업무 설정에서 좌석 기본값, 업무 소스와 Microsoft 365 권한 화면을 확인할 수 있다.

Figma의 QR, 시트 이동, 음성 재생, 녹음 및 저장 상태는 클릭 시연용 예시다. 공식 Pleos 화면 가이드는 같은 파일의 기존 페이지에서 확인할 수 있다.
